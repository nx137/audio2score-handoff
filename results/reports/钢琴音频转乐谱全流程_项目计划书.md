## 1. 背景与目标

### 1.1 现状盘点(已有资产,不要重复造轮子)

- **已完成**:基于字节跳动开源的高分辨率带踏板转录模型(Kong et al., TASLP 2021)的 **WAV→MIDI** 全流程:回归式目标编码(约 1ms 级时间定位)、速度/onset/offset/帧多模块融合、三帧拟合后处理、Sustain 踏板转录模块;结题论文《钢琴音谱智能识别技术研究》已结项。
- **已有性能**(结题论文实测):音符 onset F1 ≈ 96.7%,踏板 F1 ≈ 91.9%;已知瓶颈是误检偏高(Precision 78.4% vs Recall 96.8%,谐波误检 12.5%)。
- **已有数据**:自主构建的 500 首钢琴音频测试集 + 已部署的推理脚本。

### 1.2 为什么选这个方向(一句话)

2024–2026 年,MIDI→乐谱(PM2S)已进入 Transformer 端到端时代,有标准数据集与指标([End-to-End PM2S](https://ar5iv.labs.arxiv.org/html/2410.00210)、[Beat-Based T5](https://huggingface.co/papers/2508.19262)、[EngravingGNN](https://scirate.com/arxiv/2509.19412)),但**所有系统都忽略踏板**——而学界已公认"忽略踏板会导致时值/量化/声部分离系统性出错"([ISMIR 2022 相关讨论](https://zenodo.org/records/7676768/files/2022_Proceedings_ISMIR.pdf))。你们同时握着"毫秒级时序 + 91.9% 踏板 F1"两张牌,**踏板感知记谱是全领域空白**。

### 1.3 论文的三个主贡献(已与导师沟通过的叙事锚点)

1. **踏板感知的记谱算法**(核心):解决"物理按键时值 ≠ 踏板延长后听觉时值"的矛盾,自动生成含换踏板点的 MusicXML 踏板符号;
2. **高分辨率时序不确定性感知的量化** + 首个"AMT→记谱误差传播"定量分析;
3. **音频→可演奏乐谱开源全流程 + 基准**:扩展 MUSTER 指标至踏板域(数据底座 MAESTRO v3 + n-ASAP)。

## 2. 技术路线总览

```
音频 WAV
  │  ① 前端转录(已实现,复用现成代码)
  ▼
高分辨率 MIDI + 踏板事件          ← 已有资产
  │  ② 踏板感知量化(本项目核心)
  │      - 踏板区域分割 → 和声块
  │      - 时值推断(短音+Ped / 附点 / 延音线)
  │      - 高分辨率回归置信度加权
  ▼
MusicXML(含 <pedal> 踏板符号,含换踏板 retake)
  │  ③ 渲染与可视化(Verovio / MuseScore 导出)
  ▼
五线谱(可编辑、可打印) + (加分项:简谱投影)
```

**模块与工具选型**:

| 模块 | 选型 | 理由 |
|---|---|---|
| 前端转录 | 现有字节模型代码 | 已部署、已评测,不重做 |
| 量化/记谱 | music21(基础)+ 自研踏板感知算法;学习型量化器为可选项 | 符号处理 CPU 可跑;music21 生态成熟 |
| 踏板符号 | MusicXML 3.1 `<pedal>` 元素 / MEI `<pedal>`([标准](https://github.com/w3c-cg/musicxml/commit/28885dd42076f4ce78ed030d16501d6504f7c059)) | 标准已支持,缺的是"自动生成"这步 |
| 渲染 | Verovio(Python 绑定,输出交互 SVG);MuseScore 命令行导出 PDF 作人工对照 | 学术友好、可脚本化 |
| 评测 | MUSTER 扩展(踏板分项)+ MV2H + 踏板 F1 + 人类评测 | 与 PM2S 社区可比 |

**量化器路线决策门(见 §3 G1)**:先做"规则型量化 + 踏板先验"(必保),再评估是否有资源训"学习型量化"(增强)。**论文不依赖学习型量化器即可成立。**

### 3.3 各阶段详述

#### P0 · 立项与环境(1 周,2026-08-07 ~ 08-15)
- 任务:① 拉取 MAESTRO v3 **MIDI-only 归档**(约 56MB,含踏板标注,1276 场演奏、约 704 万音符)([MAESTRO 官方](https://magenta.tensorflow.org/datasets/maestro));② 获取 n-ASAP 对齐文件(约 700 万音符、约 100 小时乐谱对齐)([ASAP 对齐](https://research.jku.at/de/publications/automatic-note-level-score-to-performance-alignments-in-the-asap-/));③ 建立 GitHub 仓库与 Python 环境(music21、pretty_midi、verovio、miditoolkit);④ **数据可行性核对**:统计 MAESTRO v3 与 n-ASAP 的曲目重合度(决定基准构建路线)。
- 产出:环境脚本 + 数据核对报告(重合曲目清单)。
- **G0 验收**:现有转录代码能在新环境复现输出 MIDI;重合度数据拿到手。

#### P1 · M0 渲染管线(3 周,08-16 ~ 09-05,暑期密集期)
- 任务:① music21 读取现有转录 MIDI → 基础量化(规则型,先不接踏板);② 生成 MusicXML;③ Verovio 渲染 SVG 五线谱;④ MuseScore 导入人工抽查;⑤ 用自有 500 首测试集跑 10 首样例,建立"可视化质量人工评分表"(可读性/时值正确/谱面整洁三档)。
- 产出:**第一张能看的五线谱** + 评分表模板 + 渲染脚本。
- **G1 验收**:任意输入 WAV→五线谱一键跑通;★决策门:确认量化器路线(见 §5 算力),决定 P2 是否同时做学习型量化。

#### P2 · 踏板感知量化 v1(5 周,09-06 ~ 10-10,开学过渡期)
- 任务:① **踏板区域分割**:把踏板事件流切分为"和声块"(以踏板释放/换踩为界);② **时值推断**:在每块内判定每音"短按键+踏板延音 / 附点 / 延音线",输出记谱时值;③ **踏板符号生成**:块边界 → MusicXML `<pedal start/change/stop>`,换踏板 retake 落在正确拍位、谱下放置;④ 回归置信度加权(把回归峰值高度作为 onset 时序不确定度,影响量化权重)。
- 产出:踏板增强的 MusicXML + 5 首可视化对照样例(有/无踏板两版)。
- **G2 验收**:踏板符号能在谱面正确显示;对照样例肉眼可辨差异。

#### P3 · 基准构建 + 基线复现(5 周,10-11 ~ 11-15,学期中)
- 任务:① 构建"音频→乐谱"评测子集:MAESTRO v3 测试集(踏板 MIDI 真值)+ n-ASAP 对齐子集 + 自有 500 首;② **扩展 MUSTER**:增加"踏板符号位置误差、踏板感知时值误差、换踏板点误差"三个分项;③ 复现 1–2 个无踏板基线(优先开源 [PM2S toolbox](https://scholar.archive.org/fatcat/release/dov2w4sjbjds5i4w36etow75sa) 或 [Beat-Based T5](https://huggingface.co/papers/2508.19262),取其一);④ 跑通评测脚本,拿到**无踏板基线数字**。

## 6. 实验设计(研究假说 → 实验矩阵 → 预期结果)

### 6.1 研究假说
- H1:**忽略踏板会显著劣化乐谱时值与声部分割**(无踏板基线 vs 本方法,时值误差/声部错误率差异显著);
- H2:**回归置信度加权能提升转录噪声下的量化稳健性**(消融对比);
- H3:**换踏板点可被自动检测并正确落到拍位**(换踏板点 F1 与位置误差);
- H4:**转录误差会以可量化的倍率传导为乐谱错误,其中谐波误检是最大来源**(误差传播曲线)。

### 6.2 实验矩阵
| 实验 | 配置 | 指标 | 目标结果 |
|---|---|---|---|
| E1 主结果 | 全流程 vs 无踏板基线(2 个开源基线) | MUSTER 扩展/MV2H/踏板 F1 | 踏板分项显著优于基线;整体 MUSTER 不劣化 |
| E2 消融 | ±踏板分割、±置信度加权、±三惯例 | 分项误差 | 每项有正向贡献 |
| E3 误差传播 | 谐波误检 0→12.5%→25%、offset ±5/10ms 注入 | 乐谱错误率 | 单调递增,量化传导率 |
| E4 人类评测 | 30+ 段 × 3–5 评审 | 可读性/可演奏性 1–5 分 | 本方法 ≥ 无踏板基线 |
| E5 鲁棒性 | 自有 500 首(失谐/噪声/低采样率) | 与 MAESTRO 的 F1 差距 | 差距 < 5%,优于文献报道基线 |

### 6.3 预期结论(论文叙事)
"踏板是钢琴记谱不可绕过的信息源;现有 PM2S 的'无踏板假设'在真实录音下会系统性出错;本方法以高分辨率时序 + 踏板感知修复这一缺陷,并给出首个可复现的音频→乐谱基准。"
