# P3：真实曲谱 MIDI → 五线谱（小节边界修复版）

本目录提供三首曲目的**转录前标准 MIDI**与本轮重新生成的 **MusicXML**，用于逐音、逐小节对比；另附 SVG 与 PNG 五线谱预览。

## 本轮修复内容

此前的超拍并非单纯由一个短休止符造成。根因是同一手被编码为单一 MusicXML voice 时，混合网格量化（如八分三连音 $$1/3$$ QL 与 32 分网格 $$1/8$$ QL）可能形成 $$1/24$$ QL 的局部重叠。旧逻辑又把“下一起音间隔”抬高到最小网格，最终令 `makeRests` 写入伪短休止并使小节超出拍号。

本轮已将单手时值截断改为使用**实际量化后起音间隔**，不再把短间隔强行抬高；并在排谱后清理与发声元素重叠的伪休止。这样既保留同起音和弦，又保证当前单声部编码的时间线不交叠。

## 验证结果

| 曲目 | 拍号 | 小节末端超出标称拍号的小节数 | 记谱输入事件 | MusicXML 合并 tie 后事件 | 自动增删音 |
|---|---:|---:|---:|---:|---:|
| 莫扎特《F 大调小步舞曲》K.4 | 3/4 | **0** | 335 | 335 | 0 / 0 |
| 斯卡拉蒂《G 大调键盘奏鸣曲》K.79 | 4/4 | **0** | 759 | 759 | 0 / 0 |
| 舒伯特《G 大调圆舞曲》D.979 | 3/4 | **0** | 390 | 390 | 0 / 0 |

验证口径：按每小节每个时间元素的 `offset + quarterLength` 检查末端，不以元素时值简单相加；延音链已在 MusicXML 侧合并后再做事件计数。三首 XML 的 tie 链也已程序扫描，未发现孤立 `stop` 或未闭合的 `start`。

> 注：Verovio 渲染仍会报告“ties left open”，但 XML 级扫描确认每条 `<tie start>` 均有对应 `<tie stop>`，且无孤立 `stop`。该提示目前更像渲染器对分谱/和弦成员级 tie 的兼容性告警，未作为音符增删判据。

## 尚待人工验收的边界

自动事件对账已确认本轮没有新增或遗漏事件，且全部小节时值合规。此前人工标注的莫扎特第 8、19、26、38 小节及斯卡拉蒂第 15 小节中的目标音，在源 MIDI / 量化事件中均能追溯到对应真实事件；其中跨小节音在 XML 中以 `start/stop` tie 表示，不应按片段重复计数。

不过，当前“同一手单 voice + 同起音 Chord”的编码仍无法忠实表达**同起音、不同持续时间**的独立声部。该限制会影响局部时值与视觉排版，后续应升级为显式多 voice 编码；本版不把这一结构限制伪装成已经彻底解决。
