# audio2score-handoff

Piano WAV to MIDI (with CC64) to MusicXML / visualized score.

This repository is a frozen, reproducible handoff snapshot dated 2026-08-19.

Start here:

- `README_HANDOFF_CN.md` - package overview and run instructions
- `NEXT_AI_CONTEXT.md` - entry points, frozen evidence, conclusion boundaries, and next steps
- `MANIFEST.md` - asset manifest
- `CHECKSUMS.sha256` - integrity checks for key assets

Frozen model weights and evaluation evidence live under `audio2score/models/` and `evals/`.
